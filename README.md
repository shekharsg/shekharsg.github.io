# Shekhar Sharan Goyal — Research Website

Static academic research website designed for GitHub Pages.

## Main pages

- `index.html` — research profile/home
- `about.html` — appointments, education, funding, mentoring, awards, service and skills
- `projects.html` — funded projects, current research and PhD research arc
- `publications.html` — peer-reviewed/accepted papers, manuscripts, datasets and conferences
- `collaborations.html` — interactive collaboration and research-area network
- `visualization.html` — interactive district nitrogen-surplus data explorer
- `outreach.html` — conferences, service, media and outreach
- `contact.html` — contact and profile links
- `Shekhar_cv.pdf` — current academic CV (July 2026 version supplied for this build)

## GitHub Pages

Upload the **contents of this folder** to the root of `shekharsg.github.io`, commit to `main`, then set **Settings → Pages → Deploy from a branch → main → /(root)**.

The site is static; no backend or build step is required. The collaboration network is implemented in vanilla JavaScript/SVG and works on GitHub Pages.
